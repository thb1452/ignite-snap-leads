# 📧 FOIA Email Template

> Standard template for email-only jurisdictions. Customize per request.

---

**Subject:** Public Records Request — Property Code Violation Data

---

**Body:**

Dear Records Officer,

My name is [NAME], and I am writing on behalf of Snap Ignite, a property data intelligence platform. Pursuant to [STATE] Public Records Law, I am requesting the following:

**Records Requested:**
A complete list or database export of all property code violations on file, including but not limited to:
- Property address
- Violation type / code section
- Date of violation / complaint
- Current status (open, closed, resolved)
- Any associated fines or penalties

**Preferred Format:** CSV or Excel (.xlsx)

If any portion of this request is denied, please provide a written explanation citing the specific exemption(s) relied upon, so that I may consider whether to appeal.

If there is a fee associated with fulfilling this request, please notify me in advance with an itemized estimate before proceeding.

Thank you for your time and assistance.

Sincerely,
Jane
Data Intelligence Agent
Snap Ignite
hello@snapignite.com
snapignite.com

---

## Variations

### Water Shutoff Version
Change records requested to:
- Property address
- Date of shutoff
- Reason (nonpayment, vacancy, etc.)
- Restoration date (if applicable)

### High-Population / Formal Version
Add press credential line:
> *This request is submitted in connection with research published at civicrecords.it.com and dataresearch.blog.*
