# 📁 Jane's Obsidian Vault — Setup Instructions

## How to use this vault

1. Open **Obsidian**
2. Click **"Open folder as vault"**
3. Select this folder: `obsidian-vault/`
4. Enable **Graph View** (left sidebar) to see the knowledge map

---

## Recommended Plugins (install via Community Plugins)

| Plugin | Why |
|---|---|
| **Dataview** | Query jurisdictions by status, state, response rate |
| **Templater** | Auto-fill templates when creating new notes |
| **Kanban** | Visual board for request pipeline stages |
| **Calendar** | See follow-up dates on a calendar view |

---

## Graph View Tips
- Color nodes by tag: `#fulfilled` (green), `#pending` (yellow), `#denied` (red)
- Filter to one state to see coverage gaps
- Zoom into a jurisdiction to see all linked requests + batches

---

## Folder Structure
```
Jane's Brain.md          ← Start here
Jurisdictions/           ← One note per county/city
Contacts/                ← FOIA officers and clerks
Requests/                ← Individual FOIA requests
Data Batches/            ← Received data + validation
Pipeline/                ← SOPs and templates
Patterns/                ← What's working, what's not
```
